# Archive

Older releases of the Requests plugin, kept for reference. They are no longer offered in the
plugin catalog: the live [`manifest.json`](../manifest.json) lists only the current version.

- `releases/` — release packages 1.0.0 through 1.0.0.72 (`downloaded/` holds an early copy of 1.0.0).
- `manifest-history.json` — the catalog manifest as it was before archiving, with every
  version's changelog, checksum and download URL.

To make an old version installable again, copy its entry from `manifest-history.json` back into
the `versions` list in `manifest.json` (its GitHub release must still exist).
